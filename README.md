# Hi, I'm Tedj El Moulk Sinacer

### Embedded Systems & Instrumentation Engineer

Passionate about robotics, electronics and developing software that interacts with the physical world. I enjoy combining programming, sensors and hardware to build practical systems and understand how they work.

I graduated from Institut Galilée, Université Sorbonne Paris Nord. During my final-year internship at IGN/LASTIG, I developed C++ acquisition software for a lightweight panoramic imaging system and worked on GNSS timing, camera calibration and image processing.
